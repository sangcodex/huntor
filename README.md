# Huntor

浏览器插件采集，外加一次 REA 逆向试验。个人项目，2026.01 – 2026.05。

## 做了什么

采集执行器跑在浏览器插件里。它可以在页面内点击、翻页，把列表抽成结构化结果，再交回采集任务。

不同站点不共用同一套取数方式。固定请求直接读页面。动态渲染的页面，以及带签名、加密参数的请求，改走专用解析通道。

稳定的页面取数之外，另按 REA 做了逆向试验。脚本审查、网站 DOM 检查和抓包分析被收成 Agent 工具，自动查看脚本、请求调用栈和加密入口，并输出带证据链的结论。这条分析和插件里的稳定取数是分开的。

手机端用同样的方法做过抓包还原，用来核对桌面端看到的请求是不是同一条。

这个仓库目前只放项目说明。
