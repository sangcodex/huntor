# Huntor

放在浏览器里的采集工具，另外带一次 REA 逆向试验。个人项目，2026.01 – 2026.05。

## 项目是什么

用来采集列表页，并看清页面背后的请求。稳定取数和逆向分析是分开的两条路。

## 我做了什么

- 采集执行器做在浏览器插件里：页面内点击、翻页、抽出列表，再把结果交回任务。
- 固定请求直接读页面。动态渲染和带签名的参数改走专用解析，不和固定页面共用一套逻辑。
- REA 试验单独做：脚本审查、DOM 检查和抓包收成工具，结论带证据链，不与稳定取数混用。
- 手机端用同样的方法做过抓包还原，用来核对桌面端看到的请求是不是同一条。

这个仓库目前只放项目说明。
